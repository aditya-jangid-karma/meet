# Automation & Bitrix Automation Scripts

Repository containing core automation code and scripts for:
- `automation/`: Financial, banking, utility, and invoice processing automation scripts.
- `Bitrix new Team khushi automation/`: Team task schedulers, status trackers, and Bitrix API automations.

### Excluded:
Output files (`.xlsx`, `.csv`, `.pdf`, `.png`, etc.), zip archives, local browser profiles, and environment/cache files have been excluded.
